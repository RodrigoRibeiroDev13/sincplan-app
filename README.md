# 📊 Sincplan

O **Sincplan** é uma aplicação web desenvolvida em Streamlit para centralizar e facilitar o acesso a planilhas operacionais e administrativas. Permite visualizar e abrir rapidamente links organizados, além de contar com uma área administrativa protegida por senha para adicionar, editar ou remover links de forma dinâmica.

## 🚀 Funcionalidades

- **Acesso Rápido**: Visualização e redirecionamento direto para planilhas essenciais.
- **Painel Administrativo**: Gestão de links (adicionar, editar e remover) em tempo real, protegido por senha.
- **Persistência de Dados**: Armazenamento automático dos links em formato JSON.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Streamlit**
- **JSON**
